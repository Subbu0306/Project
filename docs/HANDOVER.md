# Handover

## Operator checklist

- Install Python 3.12+ and run `make install quality`.
- Review `.env.example`; obtain provider credentials through an approved owner.
- Keep confidential processing and cache disabled until written approvals exist.
- Confirm the provider's data handling, model ID, pricing and vision support.
- Run human-labelled evaluation before advisory production use.
- Walk through API, rubric, methodology, privacy, operations, limitations and demo documents.

## Verification record

Automated command results, clean-environment verification, dress rehearsals and dependency audit status are recorded in `reports/completion.md`. GitHub and deployment remain deferred by user instruction.
