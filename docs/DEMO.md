1. Run `make quality`.
2. Run `make demo` three times with network disconnected; confirm scores/provenance are stable and confidence warning is visible.
3. Start `make serve`; open `/docs`.
4. Submit the synthetic PDF and optional generated workbook.
5. Show nine grounded quotes, deterministic finance/MamakScore/impacts, five bands, red flags/questions/actions and request provenance.
6. Alter a quoted number in the fake provider fixture and show the controlled `UNGROUNDED_EVIDENCE` failure in tests.
7. Run the load test and explain that offline latency measures service overhead, not hosted-model SLA.
8. State limitations and human-review requirement before questions.
